# 本機驗收清單

請先使用 `python -m er_checker --demo` 測試，不需啟動遊戲。

- [ ] 查詢兩位示範隊友，切換頁籤、捲動逐場紀錄；每頁應有 20 場且明確標示示範資料。
- [ ] 空 ID、超過兩個 ID、非數字賽季 ID 應顯示錯誤而不崩潰。
- [ ] 啟用快捷鍵，以 Ctrl+Alt+E 隱藏／還原；Ctrl+Alt+Q 查詢既有 ID。
- [ ] 快捷鍵被其他程式占用時應提示失敗，按鈕仍能使用。
- [ ] 開啟／關閉置頂，調整視窗大小；關閉後重新啟動可再次註冊快捷鍵。
- [ ] 「貼上 ID」只貼入文字、不自動查詢；中日韓文 ID 正常。
- [ ] DAK.GG 開啟正確玩家頁（此按鈕會啟動瀏覽器，即使處於示範模式）。

取得 Key 後以 `python -m er_checker` 啟動。

- [ ] 存在／不存在的玩家各一位，錯誤只影響對應頁籤。
- [ ] 一般與積分模式分別查詢；對照 DAK.GG 或官方資料，注意資料更新時間差異。
- [ ] 留白賽季只顯示近期資料；有效 API 賽季 ID 顯示整季資料。
- [ ] 無近期紀錄時顯示無資料，不能誤顯示 0% 勝率。
- [ ] 無效 Key、斷網、逾時時顯示可理解錯誤，視窗仍能互動。
- [ ] 查詢中重複按快捷鍵不新增查詢工作；關閉查詢中的視窗不報錯。

官方確認此用途後，再測試遊戲視窗化／無邊框模式的可見性與快捷鍵。
回報問題時請附 Python 版本、Windows 版本、操作步驟與錯誤文字，請勿提供 API Key。
