# OCR + DAK.GG 本機驗收

## 初次執行

- [ ] 執行 `python tools/setup_runtime.py`，五種語言列出，不需 API Key。
- [ ] 雙擊 `start.cmd`，預設 DAK.GG。
- [ ] 匯入遊戲截圖，框選兩個名稱，Enter 後比較裁切字形與候選。
- [ ] 清楚時自動查詢；不確定時能直接點選候選，不需打韓文。
- [ ] RP、勝率、常用角色、TK/K/A 與 DAK.GG 一致（注意更新時間）。
- [ ] 一般模式下上方標示積分賽季摘要，下方只顯示一般對局。

## 角色 RP 與近 20 場分析

- [ ] 角色明細超過 5 個時全部列出，可捲動至最後一個。
- [ ] 2 場顯示「不足 3 場」，3 場開始顯示累積 RP / 場次（小數 1 位）。
- [ ] 對照 DAK.GG 角色頁箭頭，負 RP 不變成正數；缺少方向標記時不猜正分。
- [ ] 點場次、累積 RP、場均 RP、勝率、擊殺、傷害或角色名稱，方向箭頭與排序一致；數字不是字串排序。
- [ ] 場均 RP 由低到高時負分在前，不足 3 場和缺資料仍在末尾。
- [ ] 近 20 場分析是全部模式，比例加總約 100%（可能有四捨五入）；不足 20 場按實際樣本數計算。
- [ ] 切一般模式後，角色表仍清楚標示積分賽季、近期對局只列一般、模式分析仍列全部。
- [ ] 組隊顯示「無法判定」，不將 TERMINATE 徽章或同隊紀錄當作多排證據。

2026-10-03 開發驗證：23 個單元測試、原有 GUI smoke 與新增角色表格 GUI smoke 通過。公開玩家 `페이블` 實測取得 37 個角色（14 個負 RP 角色），積分與一般各 20 場；兩種查詢的全部模式分析均取得 20 場。角色表格視窗已目視確認。這些結果不代表遊戲內 OCR 或所有模式樣式都已驗收；混合模式計數、缺資料與不足 3 場另以離線樣本覆蓋。

## 截圖與快捷鍵

- [ ] 框選時主視窗隱藏；Enter 完成，右鍵重選，Esc 取消。
- [ ] 下一次截圖讀新的名稱，不沿用上一隊資料。
- [ ] 重啟記住位置；取消不覆寫舊設定；匯入圖片不改桌面座標。
- [ ] 啟用快捷鍵後 Ctrl+Alt+Q 截圖辨識，Ctrl+Alt+E 隱藏／還原。
- [ ] 改顯示器配置後要求重框；移動遊戲視窗／改遊戲 UI 比例後自行重框。
- [ ] 100%／125%／150% DPI 及左右副螢幕：框與實際裁切一致。
- [ ] 置頂開關正常；獨占全螢幕不在原型保證範圍。

## 錯誤與隱私

- [ ] 空白、低解析、混合文字、特殊符號不會聲稱確定正確；可以重框／換候選。
- [ ] 查無玩家、斷網、網站驗證／限制、格式變更有提示和開啟網頁按鈕。
- [ ] 兩分鐘內相同玩家／模式重查標示快取；不連續重試或按網站更新。
- [ ] 重複快捷鍵不建立並行工作；取消後不新增查詢。
- [ ] 關閉視窗後快捷鍵立即解除，瀏覽器在當前操作返回／逾時後退出。
- [ ] `.local/regions.json` 只含座標和螢幕範圍；正式程式沒有存圖、Key 或玩家紀錄。
